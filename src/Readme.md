# このブランチでやること

↑ このリポジトリ、ブランチで初めて追加した項目なので自分向けに補足
ブランチの課題: このブランチでやってることがわからなくなる。
基本、ブランチは細切れに切って、できたものからどんどん混ぜ込んで行ったり、
設計書などで運用、設計規則を作っておき、ブランチ名であらかた何をしているのかが把握できるようにすべきである。

しかしながら、個人開発ゆえにモチベやスケジュールによって期間を開けてしまう場合がある。
そのときにスムーズに復帰できるよう、Readme の一項目をメモとして運用することとした。

## ブランチ作成時の注意

Readme はブランチを切った直後に部分更新すべきである。
これにより、スムーズに revert ができ、PR が可能となる。

## PR 時の注意

PR を出す前に、ブランチ最初のコミットで Revert を行う。
また、Readme に更新がある場合は Revert 後に行う。
