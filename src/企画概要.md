# 企画概要

このドキュメントでは、My Todo Apps の企画概要を説明します。

# 目的

一つ作品を作り、技術者としてのアドバンテージを得る。

# 現状

- サーバーを構築し、簡易的な web サイトを公開した
- Python,javascript,java,rust 等多くの言語に触れてきた

# 問題点

- 多くの言語を触れたが、一つのアプリケーションとして制作した経験がない
  - アプリケーション開発経験が浅く、開発手法が身についていない
- サーバーで公開するサービスが存在しない

# 企画内容

この企画では、todo(今後やることをリスト化したものを管理する)アプリを次の条件に作成します。

- 統一したインターフェイスを設計し、たくさんの言語で実装する。
- 開発技法を画一化し、開発の効率を上げる。
  - ブランチモデルの統一
  - コミットメッセージの統一
  - ドキュメントの統一
  - テストの統一

# スケジュールとか

- 2025 年 8 月までにインターフェイスを設計
- 2025 年 10 月までに第一版成予定
