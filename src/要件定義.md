## システム構成図

```mermaid
flowchart TD
   %% 機能定義
   user["ユーザー"]
   subgraph ui["ユーザーインターフェイス"]
      login["ログイン"]
      managementTodo["todo管理"]
      listTodo["todo表示"]
      setNotification["通知設定機能"]
   end
   subgraph server["サーバー"]
      subgraph api["API"]
         userApi["ユーザーAPI"]
         todoApi["Todo API"]
         notificationApi["通知API"]
      end
      subgraph aps["アプリケーションサービス"]
         userManagementService["ユーザー管理サービス"]
         todoManagementService["Todo管理サービス"]
         notificationManagementService["通知サービス"]
      end
      subgraph db["データベース"]
         userDb["ユーザーデータベース"]
         todoDb["Todoデータベース"]
      end
   end

   %% ログインシステムの関係
   user -->|ログインする| login
   login -->|ユーザー認証要求| userApi
   userApi --> |ユーザー情報照合| userManagementService
   userManagementService --> |ユーザー情報問い合わせ| userDb

   %% Todo機能の関係
   user --> |todoを編集する| managementTodo
   user --> |todo一覧を見る| listTodo

   managementTodo --> |todo編集要求| todoApi
   listTodo --> |todo一覧要求| todoApi

   todoApi --> |todo編集適用| todoManagementService
   todoApi --> |todo一覧取得| todoManagementService

   todoManagementService --> |todo情報問い合わせ| todoDb

   %% 通知機能の関係
   user --> |通知設定を有効化する| setNotification
   setNotification --> |ユーザー通知設定適用要求| notificationApi
   notificationApi --> |ユーザー通知設定適用| notificationManagementService
   notificationManagementService --> |通知が必要なtodoを確認| todoManagementService
   notificationManagementService --> |ユーザーに通知を送信| user
```

## 背景

このシステムの目標は、たくさんの言語に触れながら実際に動作するアプリケーションを開発することです。  
なぜなら、自分自身のアプリケーション開発歴が浅く、言語への知識が偏っているからです。  
開発者の日記は、言語の理解とは null 安全性や、オブジェクト指向など言語文化の理解と考えていて、複数の言語をそれぞれ使い、文化の違いなどを理解することで、様々なユースケースに対応できるようになると考えています。  
そのため、フロントエンドとバックエンドを分けて開発すること、フロントエンドは複数のプラットフォームに対応させて開発を行うことが
このプロジェクトの目標であり、背景です。

## 用語定義

| 用語             | 定義                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------ |
| インターフェイス | システム同士やシステムの人間での情報をやりとりする部分です。入出力部とも                   |
| UI               | UserInterface(UI)は、ユーザーが直接操作できるインターフェイスです                          |
| API              | Application Programming Interface(API)は、異なるシステム同士で使われるインターフェイスです |
| REST API         | API に HTTP(S)通信を用いる、API の規格の一つです                                           |
